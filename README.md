# TomatoTargetShooter
<h1> Overview </h1>
The objective of this project is to create an engaging and interactive web-based shooting 
game where players aim and shoot at moving tomato targets within a limited time frame. 
The player accumulates points by successfully hitting the tomato targets, aiming to achieve 
the highest score possible before the timer runs out.
<h3> Game Mechanics</h3>
• Starting the Game: The game begins when the page loads or when the player clicks 
the restart button. 
• Target Movement: Tomatoes are created at random positions within the game 
container and move to new random positions every second. 
• Shooting Mechanism: The player clicks on the game container to shoot. If the bullet 
hits a target, the target disappears, and the score increases by one. A new target 
appears immediately. 
• Timing: The game runs for a total of 20 seconds, after which the final score is 
displayed in an alert box. 
• Restarting the Game: Clicking the restart button resets the score and timer, removes 
existing targets, and creates a new target to start the game afresh.
